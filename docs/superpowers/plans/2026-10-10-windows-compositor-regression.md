# Windows 海报墙花屏回归计划

> 执行方式：在当前隔离工作区直接实施、验证；最后做独立审查。

**目标：** 排查 2.5.3 海报墙悬停花屏，并使 Windows 更新必须验证实际窗口像素。

**约束：** 保留已安装客户端及配置；使用本地无账号 fixture；每次原生测试在同一 PowerShell 中读取 TESTING.md 并加载 Enter-TestEnvironment.ps1。不能把 GPU 启用或补丁日志当作无花屏的证据。

**方案：** 由独立测试工具采集真实 Windows 客户区，避免调用 WebEngine 截图或插入 GPU 等待改变竞争时序。海报墙使用真实 webAppearance 悬停样式及固定色块中心作为像素判据；高速悬停、滚动后重复检查，保留失败帧。记录完整 GPU 信息和实际包内 DLL 哈希。自动检查与真实媒体库人工复测都必须进入发布清单。
