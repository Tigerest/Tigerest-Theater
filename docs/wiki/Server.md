# 服务器与登录

**Jellyfin：** Windows 与 Android 2.9.0 起、Mac、iPad 与 Apple TV 2.9.3 起可以连接 Jellyfin 服务器：选择连接自建 Emby / Jellyfin 服务器的入口，填写完整地址（反向代理子路径如 `/jellyfin` 要保留），再用该 Jellyfin 服务器的账号登录。五个平台都实测了 10.9.11、10.10.7、10.11.0、10.11.11 与 12.2 的登录和播放（苹果三端还分别测试了根路径和 `/jellyfin` 子路径）。Apple TV 使用原生的服务器选择和登录页面。详见仓库的 [Jellyfin 连接说明](https://github.com/Tigerest/Tigerest-Theater/blob/main/docs/jellyfin-compatibility.md)。下面的 Emby 说明同样适用。

客户端负责浏览和播放，服务器提供内容与权限。安装客户端后，需要使用你有权访问的 Emby 服务器。

## 选择入口

首次启动可以选择「连接大河李斯特专属 EMBY 服务器」，或选择连接自建 Emby / Jellyfin 服务器的入口（桌面上叫「添加或连接自建 Emby / Jellyfin 服务器」，iPad／iPhone 上叫「连接自建 Emby / Jellyfin 服务器」）。

- 已有大河专属服务器权限：选择专属入口，使用该服务器账号登录。
- 有自己的或其他获授权的 Emby／Jellyfin：选择自建入口，填写地址，使用那个服务器的账号登录。
- 没有服务器账号：先向服务器维护者取得地址和访问权限。客户端安装包不会附带媒体库账号。

大河专属服务器的开通说明见[作者 B站主页](https://space.bilibili.com/12562485)中的充电说明。

## 地址怎么填

地址应是当前设备真正能访问的完整 Emby 入口，包含协议，必要时带端口和反向代理路径。

| 场景 | 示例 |
| --- | --- |
| 同一局域网，默认 HTTP 端口 | `http://192.168.1.100:8096` |
| 域名与 HTTPS | `https://emby.example.com` |
| 反向代理放在子路径 | `https://example.com/emby` |

不要把网址中的某个海报、单集详情或视频文件地址作为服务器入口。服务器维护者给出的子路径要保留；遗漏 `/emby` 可能连接到另一个网站或返回 404。

局域网地址只在可路由到该网络的环境下使用。例如手机离开家中 Wi-Fi 后，`192.168.x.x` 通常不能继续访问；这时需要维护者提供可用的远程入口。

## 登录并确认媒体库

1. 填好地址并连接，等待服务器登录页出现。
2. 输入该 Emby 服务器的账号与密码。
3. 登录后查看首页媒体库。首页只展示账号有权访问的内容。
4. 打开一部作品，检查能否正常显示详情与播放。

首页默认按观看记录排列：看过的作品按最近一次观看在前，看过后又有新一集入库的剧集随之提前，从未播放的作品按最近入库在后；「首页 → 展示顺序」可以改为最近入库、发行时间或评分，「首页 → 首页媒体夹」可以隐藏或调整首页上的媒体夹。浏览权限、可选媒体版本和下载权限由服务器决定。

服务器网页正常但个别影片无法播放时，优先检查该影片和账号的播放权限；不要仅因播放错误反复更改已能连接的服务器地址。

## 更换服务器或账号

点顶栏「客户端」按钮，选择「切换 / 管理服务器」（也可以在「客户端设置」里点「切换服务器」），回到服务器选择页面：连接过的自建服务器以卡片列出，点卡片即可切换，也可以编辑地址或移除，或者重新选择大河专属入口、填写新地址。换账号使用 Emby 自身的退出和登录流程。Apple TV 使用原生的服务器选择页面。

退出 Emby 或切换账号时，当前评论、回复预览、图片与未发送草稿会清理；重新进入后按新身份加载。切换前如有较长草稿，请自行保存。

## Emby 账号与评论账号的区别

| 账号 | 用途 | 自建用户向谁登录 |
| --- | --- | --- |
| Emby 账号 | 媒体库、播放、进度和服务器权限 | 自己的 Emby 服务器 |
| 独立评论账号 | 公共评论、回复、头像与公共消息 | 中央公共评论服务 |
| 大河自动评论身份 | 大河用户免注册参与公共讨论 | 使用已验证的大河 Emby 登录自动建立 |

自建用户的 Emby 密码、令牌、用户 ID 和服务器地址不会作为独立评论账号的凭据发给中央评论服务。发言前，客户端从自己的 Emby 读取本人头像，按需同步处理后的图片。讨论作品所需的 TMDB 和季集信息会用于公共话题匹配。

公共评论服务或弹幕服务暂时不可用时，你的 Emby 媒体库和播放仍可以独立使用。大河本服评论、私人报错及共享绑定写入有自己的服务权限，注册公共评论账号不会开通这些权限。

## 连接失败的检查顺序

1. 检查协议、域名、端口、反向代理路径。
2. 在同一设备、同一网络的浏览器打开同一个服务器入口，确认服务在线。
3. 如果局域网能用、移动网络不能用，检查远程入口和网络可达性。
4. 如果登录页能打开但账号被拒绝，联系该服务器维护者确认账号状态。
5. 记录客户端的具体错误，再参考[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。
