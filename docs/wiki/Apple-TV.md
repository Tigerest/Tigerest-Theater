# Apple TV

Apple TV 客户端是专为电视做的原生应用，用遥控器操作。它和其他平台一样连接 Emby 或 Jellyfin 服务器（Jellyfin 自 2.9.3 起）、使用同一套弹幕和评论服务，但界面与桌面、手机不同：没有 Emby 网页层，也没有桌面的「播放器设置」「媒体库设置」页面。

## 功能范围

| 功能 | Apple TV |
| --- | --- |
| 首页、媒体库海报墙、详情、选季选集 | 支持 |
| 播放、继续播放、上一集和下一集、观看进度回报 | 支持 |
| 字幕选择与时间调整 | 支持内嵌和外挂字幕 |
| 弹幕 | 自动匹配、手动搜索选集、来源与时间偏移 |
| 公共评论 | 浏览、发送、回复、删除自己的评论；需要已有的评论账号 |
| 画质 | 原生画质、轻量增强、完整桌面滤镜 |
| 一起看、RIFE、离线下载、音轨选择、直播、服务端转码、应用内更新 | 暂不提供 |

## 安装

从发行页下载 `TigerestTheater-版本-tvos.ipa`，系统要求 tvOS 26+。IPA 没有签名，需要用自己的 Apple 身份为已配对的 Apple TV 签名后安装；也可以用 Xcode 从源码构建安装。它不是 App Store 或 TestFlight 安装包，也不能和 iPad 的 IPA 互换。

更新时重新签名并覆盖安装，保持原来的应用标识和签名身份，不要先卸载。Apple TV 没有应用内更新检查，请到[发行页](https://github.com/Tigerest/Tigerest-Theater/releases/latest)查看新版本。构建说明见[Apple TV 安装与构建](https://github.com/Tigerest/Tigerest-Theater/blob/main/apple/TV/README.md)。

## 登录

1. 打开应用，选择「专属服务器」或「自建服务器」。
2. 自建服务器填写完整地址，包含 `http://` 或 `https://`，有反向代理路径时一起填写，例如 `https://example.com/emby` 或 `https://example.com/jellyfin`。
3. 输入该服务器的用户名和密码登录。可以用 iPhone 或 iPad 的键盘输入文字。
4. 登录会话保存在 Apple TV 的 Keychain 中，密码本身不保存。需要换账号时使用「退出登录」。
5. 「切换 / 管理服务器」列出连接过的服务器，标出当前使用的一个；可以直接切换、编辑地址或从列表移除（只移除列表项，不退出账号）。新地址确认能连上后才替换当前连接。

## 浏览

- **首页：** 上方大图展示当前选中的作品，下方是作品轮播；左右移动焦点预览，按下确认键打开。首页排序可选继续观看或最新入库；看过后又有新一集入库的剧集会标出「新一集未看」。
- **媒体库：** 进入后是海报墙，向下滚动会继续加载。2.9.4 起上方可以排序（名称、最近添加、发行时间、评分）和「搜索这个媒体库」；海报和剧集卡片标出「N 集未看」「✓ 已看」，看了一部分的显示进度条。
- **详情：** 显示年份、时长、类型、演职员和媒体信息。剧集可以直接在详情页切换季和集，评论区在详情信息下方。2.9.4 起详情页还会显示已看完、看到百分之几或还有几集未看。
- **画质：** 从页面顶部的「画质」进入，在播放前调整。

## 播放

| 遥控器操作 | 作用 |
| --- | --- |
| 播放／暂停键 | 播放或暂停 |
| 触控板向左／向右（控制栏隐藏时） | 后退／前进 10 秒 |
| 按下触控板（确认） | 显示播放控制 |
| Menu 键或返回键 | 关闭当前面板；控制栏显示时先收起控制栏（2.9.4 起）；都没有时退出播放 |

播放控制里有上一集、下一集、「选集」「字幕」「弹幕」，以及前进、后退 10 秒。控制栏 5 秒没有操作会自动隐藏。选集面板可以切换季，选择当前季的其他集。

**空间音频：** 2.9.3 起，AirPods 连接 Apple TV 时，5.1／7.1 音轨会以多声道交给系统做空间音频。播放时长按遥控器的电视键打开控制中心，选中 AirPods 那一项进入，就能选择空间音频的方式（如固定或头部追踪）。杜比全景声的高度信息仍会被解码成 5.1／7.1 声道。连接或断开 AirPods、功放时，客户端会自动按新的线路重新输出声音。

## 字幕

在播放控制里打开「字幕」：

- 选择内嵌字幕或外挂字幕，或「关闭字幕」。默认沿用 Emby 的字幕选择。
- 「字幕时间」每次提前或延后 0.5 秒，「重置时间」恢复。
- 应用自带中文字体，文字字幕不依赖系统字体；ASS 字幕保留原有样式和内嵌字体。

## 弹幕

播放时打开「弹幕」：

- 「启用弹幕」开关控制显示。
- 自动匹配不对时，在「手动搜索与选集」里搜索作品并选择正确的集；动画直接输入名称，电视剧可以输入「名称|tv」，电影输入「名称|dy」。
- 「重新自动匹配」重新识别当前视频。
- 「从网址加载」添加视频网站来源。
- 每个来源可以提前或延后 0.5 秒，「重置偏移」恢复。
- 开启「同时纠正共享匹配」后，手动选择的集数会提交到共享服务，其他客户端随后也会使用这个对应关系。需要当前服务器账号有权限，大河用户可以使用。

## 评论

详情页下方是评论区。

- 大河用户直接用当前 Emby 登录查看和发送评论，不需要另外登录。
- 自建服务器用户需要用已有的评论账号登录：在评论区选择「登录评论账号」。Apple TV 不提供注册，请先在其他客户端注册。自建服务器的 Emby 密码不会发给公共评论服务。
- 单集详情可以在「作品评论」和「本集评论」之间切换。评论最多 2000 字，可以回复、删除自己的评论，使用「下一页评论」「更多回复」浏览。

## 画质

| 档位 | 说明 |
| --- | --- |
| 原生画质 | 保持电视输出分辨率，优先保证播放流畅 |
| 轻量增强 | 简化的画面放大处理，保留线条细节；高帧率视频或持续掉帧时，自动降低当前这一集的处理负载，选择本身不变 |
| 完整桌面滤镜 | 与桌面版相同的完整画质增强。负载较高，Apple TV 4K（二代）在 4K 输出时可能掉帧；不够流畅时切回原生画质 |

技术实现见[技术原理 · Apple TV](https://github.com/Tigerest/Tigerest-Theater/wiki/Architecture#apple-tv)。
