# 字幕选择、延迟与样式

## 先选择正确字幕

桌面打开播放器的字幕菜单，查看视频内嵌或 Emby 提供的外置字幕轨。Android 使用「更多 → 字幕」选择；iPad 使用播放控制栏的「字幕」；Apple TV 在播放控制里打开「字幕」，可选内嵌字幕、外挂字幕或「关闭字幕」。

同一作品可能有简体、繁体、英文、双语或仅翻译外语对白的字幕。先确认选中的语言与用途；“已选字幕但多数对白没有文字”可能是选到了强制／局部字幕。

如果列表中没有需要的字幕，客户端不能凭空生成它。大河媒体可从详情页「上报问题 → 字幕缺失」反馈；自建 Emby 由自己的服务器维护者添加或修正字幕。

## 桌面加载本地文件

内置 uosc 的「加载字幕」可以选择本地字幕文件，并加入当前播放。选择与当前视频版本相匹配的文件，特别注意剧场版／电视版、不同剪辑和片头长度。

iPad 可以在「字幕」中「导入字幕」，加载本地字幕文件。Android 支持播放器读取 Emby 提供的外置字幕；弹幕菜单里的「导入 XML / JSON / ASS」是弹幕导入入口，不要把它当作普通字幕轨选择。

## 修正整体延迟

字幕内容正确、但所有台词都早或晚固定时间时，调整字幕偏移。Android 的「更多 → 字幕偏移」以秒输入，正值表示延后。Apple TV 在「字幕」里用「字幕时间」每次提前或延后 0.5 秒，「重置时间」恢复。

例如字幕比声音早 2 秒出现，设置约 `+2` 秒；字幕比声音晚 1 秒，尝试 `-1` 秒。观察同一句清晰对白确认方向。

桌面使用 Emby 网页播放界面时，可使用其字幕偏移功能。如果当前由 uosc 接管，且所用配置没有提供方便的延迟入口，可在「MPV 画质与插件」关闭「使用 uosc 接管播放界面」，按提示重启后使用网页播放控件。

先小幅调整，再跳到片中另一处检查。如果开头对齐、越往后越不齐，通常需要匹配正确版本或修复字幕时间轴，固定偏移无法一次解决。

字幕偏移和弹幕来源偏移是两套设置。只改字幕不会改变弹幕时间；弹幕问题见[弹幕教程](https://github.com/Tigerest/Tigerest-Theater/wiki/Danmaku)。

## 调整普通字幕外观

进入「设置 → 播放器设置 → 字幕」，可调字体、字号、位置、文字颜色、边框、背景颜色与透明度。

建议先调整字号和边框。文字贴近画面边缘时再调整位置；如果顶部有弹幕，可以缩小弹幕显示范围，减少遮挡。

字体设置在 Windows 默认微软雅黑粗体（西文与 Segoe UI 同一设计），在 Mac 默认苹方中粗体，中文字形都完整，弹幕也使用同一字体；不想要粗体可关闭「字幕粗体」（只作用于 SRT 等纯文本字幕）。改选 Segoe UI 时，中文由系统逐字挑选回退字体，同一行可能粗细不一。ASS 字幕通常优先使用脚本自带字体。字体选择不是翻译功能，也不会把繁体转换成简体。

## 保留 ASS 特效

ASS/SSA 字幕可包含排版、定位、字体、颜色、卡拉 OK 和招牌效果。随意强制覆盖可能破坏这些内容。

「ASS 字幕样式覆盖」可选：

| 选项 | 使用目的 |
| --- | --- |
| 默认（由 MPV 判断） | 日常默认行为 |
| 遵循字幕脚本 | 尽量完整保留字幕原样 |
| 应用客户端样式 | 使用客户端的字幕样式选项 |
| 仅额外覆盖缩放 | 保留原样并额外调整缩放 |
| 强制覆盖全部样式 | 强行套用设置，可能破坏特效 |
| 移除 ASS 样式与标签 | 去掉标签与特效，适合明确要纯文字显示时 |

如果调整字号后特效字幕没有变化，先检查样式覆盖规则；它可能正在正确遵循字幕自己的排版。只想恢复原版效果时，选「遵循字幕脚本」并重新检查。

「ASS 边框与阴影按分辨率缩放」用于让文字边框与阴影随视频分辨率同比变化。桌面「字幕混合阶段」默认不把字幕混进视频 shader 链，以保留字幕清晰度、颜色和排版。

## 设置优先语言

桌面「MPV 画质与插件」提供「首选音轨语言」「首选字幕语言」。可以按 MPV 的语言列表语法填写，例如字幕 `chi,zh,chs,sc,eng`。留空时跟随 Emby 的选择。

语言偏好只能在实际存在并被正确标记的轨道之间选择。若服务器没有正确标注语言，请手动选轨或修正媒体元数据。

## 排查速查

| 现象 | 先检查 |
| --- | --- |
| 完全没字幕 | 是否选中字幕、该位置是否确有台词、轨道是否只含局部对白 |
| 字体或招牌错位 | ASS 是否被强制覆盖、片源与字幕是否匹配 |
| 字幕整体早／晚 | 调整字幕偏移 |
| 越往后越不齐 | 是否不同帧率或剪辑版本，换用对应字幕 |
| 改字号没效果 | ASS 样式覆盖规则、mpv.conf 用户区是否写了覆盖字幕样式的参数 |
| 字幕和弹幕互相遮挡 | 缩小弹幕范围或调整字幕位置 |

反馈时提供作品、季集、所选字幕名称、问题时间点与截图。大河用户的操作入口见[私人问题上报](https://github.com/Tigerest/Tigerest-Theater/wiki/Messages-and-Reports)。
