# 下载与离线媒体

Windows、Mac 和 iPad／iPhone 提供下载与离线媒体管理。Android 和 Apple TV 当前不提供此功能；Android 的“更新下载”是下载客户端 APK，不是下载影片。

## 下载前确认权限

Emby 服务器决定账号能否下载、可以下载什么媒体。客户端有下载管理器不代表账号自动获得下载权限。

如果作品详情没有下载入口，先确认服务器是否允许当前账号下载，以及当前条目是否可下载。不要通过更换公共评论账号来处理媒体下载权限。

## 创建下载

1. 连接 Emby，登录有下载权限的账号。
2. 打开需要保存的电影或单集详情。
3. 使用 Emby 详情页的下载按钮创建任务。
4. 打开客户端设置，点击「打开下载与离线媒体管理」；iPad 打开「离线媒体」。
5. 查看对应任务的状态，等待完成。

文件保存在当前客户端用户目录中，不会修改服务器媒体。为完整视频和正在下载的数据准备足够磁盘空间。

## 管理任务

任务进行中可以暂停；暂停后点击「继续」恢复。完成后出现「播放」入口。失败时先查看错误，修正原因后再从详情页发起下载。

「删除」会移除本地下载任务及相关文件，请确认不再需要这份离线副本后再操作。它不会删除服务器上的原始影片。

不要在任务进行时手动移动下载目录或删除临时文件。遇到权限、空间或连接错误，先解决对应原因再继续任务。

## 离线播放

从「打开下载与离线媒体管理」中找到已完成的媒体，点击「播放」。iPad 在「离线媒体」中播放，也可以用「导入媒体」加入已有的视频文件。离线内容使用本地文件，不必重新从服务器串流整部视频。

出门前可以先断开网络试播一次，确认文件已经完整下载、音轨与字幕满足需要。作品评论、公共消息和在线弹幕仍依赖网络；保存视频不等于把这些在线服务一并离线保存。

离线文件是否具有所需字幕，取决于实际下载内容。不要仅凭在线播放时见过字幕，就假定本地副本已经带上所有外置字幕。

## 更新时保留什么

安装版与 Mac 替换程序时保留用户数据。Windows 便携版更新前备份并保留 `data`，其中包含配置档及相关离线数据。iPad／iPhone 重新签名后覆盖安装会保留离线媒体；卸载应用会删除它们。从 2.9.3 及更早的 iPad 版换到 2.9.4 的通用包时，系统把它当成新应用，旧版里的离线媒体不会迁移，需要在新版里重新下载；删除旧版会一并删除旧版里的离线文件。

不同配置档分别管理设置和离线文件。如果任务“消失”，先确认启动的是原来的安装版／便携目录和配置档，再检查文件是否仍在。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 没有下载按钮 | 当前 Emby 账号权限、条目是否可下载 |
| 任务无法继续 | 网络、登录状态、磁盘空间和目录写权限 |
| 离线列表空了 | 是否换了配置档、便携目录或删除了 data |
| 文件能播但没字幕 | 实际下载文件是否含字幕，是否需要对应外置字幕 |
| 离线时评论／弹幕失败 | 这些在线服务仍需要联网 |

如果反复失败，保留具体错误与版本信息，按[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)准备反馈。
