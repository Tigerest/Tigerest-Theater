# 播放操作与客户端设置

## 找到设置

进入 Emby 设置，左侧菜单分成两组：「播放器设置」包括客户端、视频、音频、字幕、MPV 画质与插件和弹幕样式；「媒体库设置」是首页等与媒体库浏览相关的分类。也可以点顶栏「客户端」按钮，选择「播放器设置（MPV）」或「客户端设置」；打开 MPV 画质与插件的快捷键为 Windows 的 `Ctrl+,`、Mac 的 `Cmd+,`。

窄屏通过 Emby 菜单抽屉访问，同样分成两组。Android 和 iPad／iPhone 仅显示该平台支持的项目。Apple TV 没有这个设置页，画质等选项在电视端页面里调整，见 [Apple TV](https://github.com/Tigerest/Tigerest-Theater/wiki/Apple-TV)。分类内容支持搜索、即时保存和恢复默认值；界面标明「需要重启」的项目，要完全退出后重新打开。

| 分组 | 分类 | 常用设置 |
| --- | --- | --- |
| 播放器设置 | 客户端 | 更新检查、切换服务器、Windows 托盘、离线媒体入口 |
| 播放器设置 | 视频 | 硬件解码、缓存、画面比例、速度、桌面 RIFE |
| 播放器设置 | 音频 | 输出设备、声道、标准化、直通 |
| 播放器设置 | 字幕 | 字体、字号、位置、颜色、ASS 样式覆盖 |
| 播放器设置 | MPV 画质与插件 | 渲染后端、uosc 与弹幕插件、画质档，以及桌面的 mpv.conf 编辑器 |
| 播放器设置 | 弹幕样式 | 字号、描边、透明度、滚动时长、显示范围 |
| 媒体库设置 | 首页 | 启动时自动全屏；展示顺序：继续观看、最近入库、发行时间或评分；首页显示哪些媒体夹及其顺序 |

设置出现“已保存并应用”时可直接观察；RIFE 模型和目标帧率更改要重新打开视频，渲染后端和插件开关更改要重启。

## 首页媒体夹

2.8.0 起，「首页 → 首页媒体夹」列出当前账号可以在首页看到的媒体夹。取消勾选可以在首页隐藏，「上移」「下移」调整顺序，修改即时保存；「恢复服务器默认顺序」回到服务器原来的排列。

- 首页至少保留一个媒体夹。
- 设置按服务器和账号分别保存，只在这台设备上生效，不会改动服务器或其他设备。
- 服务器上新增的媒体夹会自动排在末尾并显示。
- 大河服务器的首页固定展示三个媒体夹和「收藏」，这里只能在这几项之间隐藏和排序。

## 首页全屏与窗口

桌面首页「我的媒体」标题右侧提供切换按钮：窗口状态进入全屏，全屏后按钮用于回到窗口。

在「首页 → 启动时自动全屏」中决定下次启动的行为，默认关闭。改变这个开关不会立即切换当前窗口；手动点击按钮或使用 F11 也不会改写启动偏好。

Windows 窗口模式下，按住顶部标题栏拖到屏幕左边或右边，可以吸附为半屏；拖到顶边最大化。从吸附或最大化状态拖出标题栏，可恢复原窗口尺寸。全屏时先通过首页按钮或 F11 回到窗口，再使用系统吸附。

首页按钮与其他页面的顶部按钮采用统一样式；更新提示红点、消息数量和「客户端」按钮的金色样式保留。**已知问题：** 部分 Windows 高刷新率环境下，窗口播放可能持续卡顿、增加输出丢帧，而全屏正常。2.9.5 仍未修复；遇到此现象请先使用全屏播放。详见[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。

### 首页观看进度

底部轮播海报右上角的红点表示作品还有未观看内容。剧集同时显示「观看进度：8/12」：8 是当前账号标记已看的集数，12 是当前服务器返回的现有剧集数，不是预计完结集数。全部看完时不显示红点；电影只显示观看状态。

集数在首页出现后异步补齐。播放结束返回首页会重新读取，服务器尚未收到播放进度时可能稍后才更新。无法获取可靠集数时隐藏数字，不显示猜测的 0/0。

## 桌面播放

打开作品详情并播放。控制栏提供暂停、进度、音轨、字幕、队列和选集；上一集、下一集沿用 Emby 实际播放队列。从剧集页点「播放」时 Emby 只排当前这一集，这时播放列表列出这一季的各集，选集、上一集／下一集会从选中的那一集重新开始播放（2.9.5 起）。Windows 默认在主窗口内播放，Mac 默认使用独立 GPU-Next 播放窗口，停止后回到媒体库。

内置桌面快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 播放／暂停 | 空格 |
| 全屏 | F11 |
| 增减音量 | ↑ / ↓，每次 5 |
| 减慢／加快速度 | X / C |
| 恢复 1 倍速 | Z |
| 返回上一帧／下一帧 | D / F |
| 停止并返回媒体库 | Esc / Q |
| 完整退出 Windows 客户端 | Alt+F4（播放中也适用） |
| 统计总览 | Ctrl+J |
| 完整处理耗时页 | Ctrl+Shift+J，或统计中按 2 |
| 默认／真人／激进测试画质 | Alt+1 / Alt+2 / Alt+3 |

快捷键由客户端内置的 input.conf 定义。桌面右键打开播放菜单，双击画面切换暂停。

Windows 的 Alt+F4 始终请求完整退出，包括启用托盘时。若设置了关闭到托盘，右上角红叉仍按该设置隐藏窗口；托盘菜单「退出」会完整退出。播放中退出时，客户端先停止播放器、释放原生视频窗口，再结束进程。

## 播放本地视频（Windows 与 Mac）

2.9.5 起大河影院可以当本地播放器用，不需要媒体服务器：

- 在资源管理器里对视频右键「打开方式」选大河影院，或把视频拖到大河影院的快捷方式上；也可以在服务器选择页或客户端菜单点「打开本地视频」（`Ctrl+O`）。安装版把大河影院加进 24 种视频格式的「打开方式」列表，不改默认播放器；想默认用它打开，在 Windows 的「默认应用」里选择。
- 单独打开一集时，同一文件夹里的视频按文件名排成播放列表（第 2 集在第 10 集前面），从这一集开始，播完接下一集；一次选中多个文件打开时，列表就是这些文件。控制栏的播放列表、上一个／下一个、任务栏和媒体键都在列表里切换。
- Mac：在访达里对视频选「打开方式 → 大河影院」，或拖到程序坞里的大河影院图标上；「打开本地视频」的快捷键是 `⌘O`。同样只加进「打开方式」，想默认用大河影院打开，在视频的「显示简介 → 打开方式」里选择后点「全部更改」。在访达里一次选中多个文件打开，列表就是这些文件。
- 大河影院已经开着时再打开文件，交给已打开的窗口播放。
- 本地播放不搜索、不加载弹幕，不上报播放进度，没有评论和一起看；用文件启动时不自动连接服务器。音轨和字幕由 mpv 自动选择，同名外挂字幕自动加载。
- 列表最后一个播完或停止后回到服务器选择页；打不开的文件会提示文件名，并接着播下一个。

## 音量与音轨

播放器面板和滚轮调节的音量会记住，换集保留当前值。2.6.0 修复了音量单位混用造成退出后错误变成 0 的问题。

首次默认音量为 100。为修复旧版本遗留数据，新音量记录首次初始化时会把旧版保存的 0 恢复为 100，已有非零音量继续保留。之后记住手动调整的值，包括主动设为 0，重新打开不会再次强制恢复为 100。

先从播放菜单选择需要的音轨。遇到无声时，检查播放器和系统媒体音量、静音、当前输出设备，再检查是否选择了设备不支持的直通格式。

普通扬声器或耳机可以先用基础输出。S/PDIF 或 HDMI 直通需要连接设备支持相应格式；只按实际设备启用 AC3、DTS、E-AC3、DTS-HD 或 TrueHD。独占音频默认关闭。

## 画质预设

桌面「MPV 画质与插件 → 画质 / 着色器预设」提供三个档位：

- 默认：Anime AA 高强度。
- 真人影视高画质：用于真人影视的预设。
- 激进测试：Anime4K 完整链，用于比较和测试，负载较高。

`Alt+1` 恢复当前默认画质档，`Alt+2` 切真人档，`Alt+3` 切激进测试档。切换画质会保留已运行的 RIFE 链路，未开启 RIFE 时不会自动添加补帧。

切档会整组切换该档位的参数。在设置页选择画质预设后，下方表单编辑的就是这一档；播放中用 uosc「滤镜」按钮或 Alt+1/2/3 切档时，设置页的画质预设同步切换。

## 硬件解码、缓存和渲染

日常先保留默认硬件解码。个别文件花屏时，可暂时关闭硬解作比较；如果关闭后正常，记录片源编码、显卡和驱动信息。

持续网络缓冲时检查线路与服务器吞吐，再按需要调整「网络缓存大小」及「缓存不足时自动暂停」。缓存能吸收短时波动，无法补足长期低于片源码率的网络速度。

桌面默认使用 GPU-Next；发生兼容问题时可在「视频渲染后端」试用「libmpv Render API 兼容模式」，更改后重启。这是视频输出后端；网页界面的 GPU 问题有独立排查方式。

## HDR 播放

**Windows：** 播放 HDR 片源时，如果显示器支持 HDR 而 Windows 没有开启，客户端自动开启系统 HDR，播放 SDR 片源、停止播放约 8 秒后或退出时恢复；只恢复客户端自己打开的那一次，异常退出后下次启动也会恢复。切换时屏幕会黑一两秒。不需要时在「播放 HDR 时自动开启系统 HDR」关闭。系统 HDR 开启时客户端不使用 Windows 的 HDR 校准配置文件作色彩目标，而是以 HDR10 输出、按显示器峰值亮度映射。

**Android：** 在支持 HDR 的屏幕上，HDR10 和 HLG 视频由系统直接按 HDR 显示；不支持 HDR 的屏幕上由播放器色调映射为 SDR。直接输出 HDR 时文本字幕仍按字幕设置显示，图形字幕（PGS 等）和没有 HDR10 基础层的杜比视界改用色调映射。手机的高温保护会降低 HDR 峰值亮度，这时画面看起来不够亮属于系统限制。开始播放时左上角显示几秒输出方式，例如「HDR 输出 · HDR10」或「SDR 输出 · HDR10 已色调映射」，以及片源与输出的色彩空间。

**Mac 与 iPad：** 在支持 HDR 的屏幕上（例如 MacBook Pro 的 XDR 屏、iPad Pro），HDR10 和杜比视界直接以 HDR 输出，高光不再被压到 SDR 白；普通 SDR 屏幕（如 MacBook Air、多数外接显示器和 iPad）保持以前的色调映射。开始播放时显示 4 秒输出方式和片源、输出的色彩空间：Mac 在画面右上角，不与弹幕提示重叠；iPad 显示在播放画面上。在 mpv.conf 里手动指定过 ICC 配置时，按你的设置处理。

**Apple TV：** 未专门适配 HDR 输出，沿用原来的播放方式。

## 自定义 mpv.conf（Windows 与 Mac）

2.9.4 起客户端只使用自己目录里的一份 mpv.conf，在「设置 → 播放器设置 → MPV 画质与插件」下方的编辑器里修改。旧版的配置模式（内置 / 自动 / 系统）、「高级 → 手动 MPV 配置」和 user-overrides.conf 都不再生效；升级时旧内容会备份到配置目录里的「旧版自定义配置备份.txt」，需要的话在编辑器里重新设置。

- 文件分三块：灰色的头部和尾部由客户端维护，写着由软件和其他设置页（视频、字幕、音频）决定的配置；中间的用户区可以自由修改。
- 上方表单和下方文本实时同步。左侧每两行之间的「+」可以插入画质参数、着色器、vf 滤镜或新建自定义档位（以 tigerest-user- 开头，会出现在画质预设和 uosc「滤镜」菜单里）。
- 没有错误时自动保存并立即生效；有错误时标红并暂不保存，离开设置页会询问「强行使用」还是「返回修改」。
- 与已开启的 RIFE 冲突的行（改变帧率的 vf 滤镜、`interpolation=yes`）会被标黄并暂停执行，关闭 RIFE 后自动恢复。
- 自己的 .glsl 放在编辑器里「打开我的着色器目录」打开的 shaders/user 目录，升级不会改动它。内置滤镜库清单列出每个着色器的作用、触发条件、开销和强度。
- 想让 AI 帮忙改配置时，点「复制给 AI」，把复制的说明和完整配置一起交给 AI，再把它返回的完整文本粘贴回编辑器；粘贴后会先显示改动。
- 写坏了可以点「恢复默认配置」；mpv 无法用你的配置启动时，客户端会自动改用默认配置并提示。

## Android 操作

轻触画面显示或隐藏控制栏。常用暂停、前后跳转、选集、上一集、下一集、弹幕和倍速直接可见；「更多」中提供音轨、字幕、字幕偏移、画质、播放器设置和手势教程。

| 手势 | 作用 |
| --- | --- |
| 双击空白画面 | 播放／暂停 |
| 左右滑动 | 预览跳转位置，松手后提交 |
| 左侧上下滑动 | 调整本次播放窗口亮度 |
| 右侧上下滑动 | 调整系统媒体音量 |
| 长按空白画面 | 临时至少 2 倍速，松手恢复；原速度更高时保持原速度 |

从画面内部开始手势，避免按钮、进度条和系统边缘区域。第一次播放会显示教程，也可在「更多 → 手势教程」重看。

「防误触」会隐藏控制栏并屏蔽手势与返回；长按「长按解锁」恢复。系统关闭自动旋转时保留当前方向，换集或浏览页面仍生效；重新开启自动旋转恢复系统控制。

Android 切到后台会暂停，当前不提供后台持续播放、画中画、桌面 RIFE 或离线下载。

## iPad 操作

iPhone 使用同一个 iPhone／iPad 通用包和同一套播放器，竖屏时控制栏分成时间和按钮两行。浏览页面时，从屏幕左边缘向右滑动返回上一层（与顶栏返回相同）。

播放时隐藏系统状态栏。轻触画面显示或隐藏控制栏；控制栏提供播放／暂停、上一集、下一集、选集（显示 SXXEXX 季集号）、音轨、字幕、弹幕、锁定和「手势教程」。

| 手势 | 作用 |
| --- | --- |
| 双击画面 | 播放／暂停 |
| 左右滑动 | 预览快进或快退位置，松手后跳转 |
| 左侧上下滑动 | 调整本次播放的亮度，退出播放后恢复 |
| 右侧上下滑动 | 调整系统媒体音量 |
| 长按空白画面 | 临时 2 倍速，松手恢复；原速度超过 2 倍时保持原速度 |

请从画面内部开始滑动，屏幕边缘留给系统手势。「锁定」后屏蔽手势，提示会自动隐藏；轻点画面唤回按钮，长按解锁恢复操作。

连接妙控键盘或其他实体键盘时：

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放／暂停 |
| ↑ ／ ↓ | 调整系统音量，每次一格，按住连续调整 |
| ← ／ → | 快退／快进 15 秒；按住 ← 连续快退 |
| 按住 → | 临时至少 2 倍速，松开恢复 |

带修饰键（如 ⌘、⌥）的方向键保持系统原有作用。锁定时按方向键会显示解锁按钮。

戴 AirPods 播放 5.1／7.1 音轨时，客户端保留多声道交给系统，控制中心可以打开「空间音频」；以前会先混成立体声。杜比全景声的高度信息仍会被解码成 5.1／7.1 声道。连接或断开耳机、AirPlay 时自动按新的声道数重新输出。

画质预设和 RIFE 在客户端设置中调整，见下文[画质预设](#画质预设)和 [RIFE 补帧](https://github.com/Tigerest/Tigerest-Theater/wiki/RIFE)。

## 一起看时的播放

在[一起看](https://github.com/Tigerest/Tigerest-Theater/wiki/Watch-Together)房间里播放时，暂停、播放、拖动和换片会同步给房间里的其他人，播放速度固定为 1 倍。播放器里会提示是谁做了操作。
