# v2.5.3 转场点击响应优化

采用已通过 Windows 试用确认的 [PR #3](https://github.com/Tigerest/Tigerest-Theater/pull/3) 方案，减少首页、媒体夹与详情转场在点击后的准备停顿。

- 海报转场优先使用预热的低分辨率背景位图，减少整页复制和重新布局。
- 悬停切换作品后立即点击时，不再等待标题与简介动效结束；缓存未就绪时先模糊当前页面。
- 目标页面使用实时毛玻璃衔接，减少海报起飞前的页面复制与图片解码。
- 首页进入媒体夹时直接动画导航栏、舞台和轮播；返回首页原地显示预热快照，保留原开屏动效。
- 保留首页排序、触屏聚焦点击、对应媒体夹返回与海报落点校准；已有 Windows RIFE 扩展继续兼容。
