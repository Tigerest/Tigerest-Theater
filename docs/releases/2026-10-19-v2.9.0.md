| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Windows 安装版 | [2.9.0 EXE][dl-win-exe] | Windows 10 1903+ / Windows 11，x64 |
| Windows 便携版 | [2.9.0 ZIP][dl-win-zip] | 同上；完整解压后运行 |
| Android | [2.9.0 APK][dl-android] | Android 15+，arm64-v8a / x86_64 |
| Apple Silicon Mac | [2.8.0 DMG][dl-mac] | macOS 26+，M 系列芯片 |
| iPad | [2.8.0 IPA][dl-ipad] | iPadOS 26+，须自行签名安装 |
| Apple TV | [2.8.0 IPA][dl-tvos] | tvOS 26+，须为 Apple TV 签名安装 |

本次发布 **Windows 与 Android**。Mac、iPad 与 Apple TV 的 2.9.0 在 Mac 上构建和验证后补充到同一发行页；在此之前它们继续使用 [2.8.0](2026-10-16-v2.8.0.md)，Mac 与 iPad 的更新检查也停在 2.8.0。

## Jellyfin 服务器

在「自建服务器」里填写 Jellyfin 地址，再用该服务器的账号登录。反向代理带 `/jellyfin` 这类子路径时要完整保留。地址格式与账号范围见 [Jellyfin 连接与兼容范围](../jellyfin-compatibility.md)。

- 适配服务类型识别、鉴权、媒体列表与首页字段、图片和字幕地址、MPV 播放、进度上报与续播；Windows 另支持 Jellyfin 的离线下载。
- 首页、媒体库、详情页的转场动画和深色顶栏与 Emby 保持一致，Jellyfin 12 的 Modern 与 Legacy 两种布局都适配。
- 公共评论使用独立的评论账号。连接 Jellyfin 不会获得大河专属的身份、私人报错、共享弹幕绑定写入或一起看权限。

## 服务器列表与「客户端」菜单

- 切换服务器页面会记住连接过的自建 Emby／Jellyfin 服务器。点卡片即可切换（整张卡都可以点，鼠标悬停时高亮），也可以编辑地址或从列表移除；移除不会退出登录或删除服务器上的内容。
- 顶栏的 MPV 设置和切换服务器合并为一个「客户端」菜单，首页也有服务器入口。
- 切换失败（服务器不可达、返回错误页）时保留原服务器和登录，不会写入半成品设置。

## 修复与改进

- **Windows 花屏：** 首页轮播空闲、窗口被其他窗口挡住时，偶尔出现整页只剩背景、卡片块状缺失或闪暗。原因是 Chromium 重写共享纹理时 Qt 可能还在读上一帧。修补版 QtWebEngine 新增双向 D3D11 fence 同步：两边都在 GPU 队列上等待，CPU 不阻塞；显卡不支持共享 fence 时自动回退到原有的同步方式。
- **首页轮播：** 换作品时新旧海报和背景交叉淡化，不再闪暗；新图迟迟加载不出来时，旧图仍会按时淡出。
- **媒体库入场：** 进入媒体库时整页飞入，不再先显示加载圈。
- **Jellyfin 头像：** 顶栏头像完整显示，此前只显示为一个浅色空白圆。
- **Android：** 视频在播放器画面就绪后才开始；Jellyfin 页面切换时原生桥保持连接，不再断开。
- **Android 折叠屏：** 在外屏启动应用时，WebView 会以手机身份打开网页，Jellyfin 随之切到它的手机布局，导致媒体库首行被标签栏盖住、展开后详情页海报压住标题。现在内外屏都使用同一套布局，与启动时用的是哪块屏幕无关。
- **首页重复作品：** 服务器上同一部作品有两个条目时，首页按作品身份合并为一张卡。这项修复原定在 2.8.1 发布，2.8.1 没有单独发布，随本版一起提供（[2.8.1 说明](2026-10-17-v2.8.1.md)）。

## 安装

- `TigerestTheater-2.9.0-x64.exe`：Windows 安装版；或完整解压 `TigerestTheater-2.9.0-x64.zip` 便携版。Windows 2.5.1 及之后可用内置更新，更新前完全退出客户端；便携版保留 `data`。未做 Authenticode 签名。
- `TigerestTheater-2.9.0-android.apk`：Android 15+，沿用原签名，可覆盖升级并保留登录。
- `TigerestTheater-2.9.0-SHA256SUMS.txt` 校验以上文件；`RELEASE-MANIFEST.json` 记录来源提交和验证范围。源码：`client-Sources.zip`、`android-Sources.zip`。
- `TigerestWebEngine-6.9.3-d3d11.zip`：本版 Windows 使用的修补版 QtWebEngine 组件（四个补丁），供构建工作流和自行重建使用，普通用户不需要下载。
- 已安装的 Windows RIFE 扩展可以继续用于 2.9.0。

## 验证范围

- **自动测试：** Windows 发布构建完整 CTest 109/109 通过（555 s）。按条件跳过的用例与 2.8.0 相同：会移动真实鼠标的 5 个窗口吸附／指针用例，以及需要私有 RIFE 运行库、固定源码或显卡的 RIFE 用例；本次 `test_window_chrome` 的无边框最大化检查实际运行，没有跳过。Android JVM 测试 debug 124/124、release 121/121，`lintRelease` 0 个错误。页面类测试使用隔离配置和模拟数据。
- **Windows 安装包：** 便携版 ZIP 的 1532 个文件与暂存目录逐字节一致；OpenSSL、MPV 与修补版 QtWebEngine（4 个补丁）的哈希与锁定值一致。解压到空目录、只保留系统目录 PATH 启动，窗口和网页进程正常，Qt、WebEngine、MPV、OpenSSL 都从包内加载。
- **Jellyfin：** 各版本的登录、首页、播放、音轨／字幕、跳转与续播在真实 Jellyfin 服务器上实测，记录见 [Jellyfin 2.9.0 验收记录](../verification/2026-10-19-jellyfin-2.9.0.md)。
- **Windows 花屏：** 同条件 6 分钟抓帧，整页花屏帧由 5–26 帧降到 0，记录见 [D3D11 fence 同步验证](../verification/2026-10-20-d3d11-fence-sync.md)。CTest 另检查 fence 同步实际启用，以及关闭后回退到原同步方式。
- **Android 真机（小米 MIX Fold 4）：** 在真实 Jellyfin 服务器上，用调试版测试外屏竖屏／横屏、内屏竖屏／横屏，以及运行中折叠和展开：媒体库没有内容压在顶栏下，详情页海报不压标题、按钮和简介；从外屏冷启动走「首页点海报 → 详情 → 媒体库」也正常。快速滑动媒体库时系统实际呈现约 117–118 fps（外屏与内屏各两轮）；修复前的手机布局下同样操作只有 95–97 fps。最终签名的正式版已覆盖安装到这台手机，在外屏冷启动后连接大河 Emby，首页、媒体库和详情页显示正常。
- **未验证：** Mac、iPad 与 Apple TV（随后在 Mac 上构建验证）；其他 Android 机型和折叠屏；正式版在 Jellyfin 上的完整真机回归（真机布局与帧率测试使用同一份代码的调试版）。
- 最终构建的测试、签名与附件哈希以发行页的 `TigerestTheater-2.9.0-RELEASE-MANIFEST.json` 与 SHA-256 清单为准。

## 已知问题

- 部分 Windows 高刷新率环境下，窗口播放可能持续卡顿、增加输出丢帧，而全屏正常。2.9.0 仍未修复，请先使用全屏播放，见[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。
- 真实媒体库中进入媒体库或详情页时，网页主线程仍可能有 70–160 ms 的长任务，表现为一次短暂停顿，后续优化。
- Jellyfin 服务器缺少共同作品身份时，同一作品的两个条目仍可能分开显示；同名的不同作品不会按标题合并。
