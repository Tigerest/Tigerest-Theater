## 已知问题：Windows 窗口播放掉帧

**已知问题：** 部分 Windows 高刷新率环境下，窗口播放可能持续卡顿、增加输出丢帧，而全屏正常。2.6.0 尚未修复；遇到此现象请先使用全屏播放。详见[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。

已在 RTX 4090 / 240 Hz / GPU-Next / D3D11、关闭 RIFE 的真实播放中复现。纯音频时钟的实验结果不能等同于兼顾弹幕流畅度的正式修复，底层原因仍待确认。见[调查记录](../reports/2026-10-13-windowed-presentation-diagnosis.md)。

## 已实现的用户变化

### 不同 Emby 服务器一起讨论

公共评论按可靠 TMDB 标识和播出季集关联。大河用户沿用现有 Emby 登录，自建用户使用独立评论账号，支持注册、登录、退出和修改密码；未登录评论账号不能读取或发送公共评论。

自建 Emby 凭据仅用于自己的服务器。评论会话使用系统安全存储；存储不可用时会提示只在本次运行有效。元数据缺失、DVD／未知集序或合并集不猜测对应关系；找不到本地唯一作品时仍能查看公共讨论。

详情页统一显示「评论区」，移除公共／本服切换；按服务器自动选择入口，保留大河旧回复、管理员工具和私人问题上报。大河消息合并本服／公共回复和修复通知，外服只使用公共消息。

### 密码与头像

后端已开放新的密码和头像能力。注册／改密页面依据能力接口显示新服务的 8–128 个字符要求；兼容旧服务时保持 12–128。中文、emoji 和普通空格按 Unicode 码点计算，禁止控制字符，已有密码仍可登录。

大河头像由服务端从可信 Emby 同步。自建用户每次发言检查自己当前 Emby 的本人头像，评论成功后按需上传处理后的图片。头像同步失败可以单独重试，正文成功状态不受影响；账号切换和过期上传不会覆盖新账号的界面。

### 共享弹幕与音量

普通大河登录用户手动选定作品和集数后，可以保存共享绑定，无需配置管理员 JSON。共享读取仍匿名；外服 Emby 凭据和独立评论登录不用于写入。保存失败仍加载当前选择并明确提示。

桌面内置弹幕下载设为 5 秒连接、20 秒请求超时，共享查询保留 35 秒。超时、断流或临时服务错误会等待 1 秒后重试一次；空弹幕和限流不反复请求。换集、手动换源或换账号会取消旧请求，保存绑定不自动重复提交。

修复音量在网页与原生播放器之间的单位转换，退出后不再错误递减为 0。首次默认 100；旧版遗留的 0 在新音量记录首次初始化时恢复一次，旧版非零音量保留。之后记住手动设置，包括主动设为 0。

首页海报增加未观看红点，剧集显示「观看进度：8/12」。分母来自当前服务器的剧集记录，分子来自已观看记录；数据异步加载，播放返回时刷新，无法获取时不编造数值。

Windows 播放媒体时按 Alt+F4 可完整退出。退出流程先异步停止播放并确认原生视频窗口已经释放，再结束应用，修复播放中直接退出可能卡死的问题。启用托盘时，红叉继续遵循关闭到托盘偏好，Alt+F4 和托盘「退出」仍完整退出。

## 窗口功能

- Windows 使用系统窗口吸附：左右半屏、顶边最大化、拖出还原；修复自动隐藏任务栏时 Qt 误判全屏的问题。
- 首页「我的媒体」标题右侧提供全屏／窗口切换按钮，全屏后用于返回窗口。
- 「首页 → 启动时自动全屏」默认关闭，仅影响下次启动；手动 F11 或按钮不修改启动偏好。
- 首页及顶部按钮统一圆角、尺寸、边框与悬停样式，保留消息数量和更新红点；窄屏触控按钮保持足够点击范围。

实际 Windows 拖边测试已经通过，完整结果见[窗口预览验证](../reports/2026-10-13-window-controls-preview.md)。本轮用户已确认其余功能可发行。

整包重启验收另修复 MPV 初始窗口状态覆盖首页启动偏好的问题；加入四进程双向重启回归，确认启动偏好、当前窗口和手动按钮互不混淆。
