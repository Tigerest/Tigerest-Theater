# v2.5.2 首页排序与海报转场

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Windows 安装版 | [2.5.2 EXE][dl-win-exe] | Windows 10 1903+ / Windows 11，x64 |
| Windows 便携版 | [2.5.2 ZIP][dl-win-zip] | 同上；完整解压后运行 |
| Android | [2.5.2 APK][dl-android] | Android 15+，arm64-v8a / x86_64 |
| Apple Silicon Mac | [2.5.2 DMG][dl-mac] | macOS 26+，M 系列芯片 |

- 首页默认展示「继续观看」，数量不足时用「最近入库」补齐。新增「首页」设置，可选择继续观看、最近入库、发行时间或评分。
- 从首页打开作品详情后，返回该作品对应的媒体夹；轮播列表右上方提供「查看更多」。
- 手机点击已聚焦的作品或媒体夹直接进入，切换其他项时先选中，再次点击进入。
- 首页、媒体夹和详情使用同一竖版海报衔接转场，背景平滑模糊过渡；详情返回媒体夹时海报缩回列表位置。
- 首页与媒体夹之间加入飞出及中央放大淡入，返回首页保留原开屏动效。
- 预热并缓存当前页面的低分辨率背景，让海报在路由准备期间就开始变化；修复点击首帧背景偏移、返回重影与模糊边缘透底。
- 更新弹窗增加 GitHub 项目和作者 B站主页图标。
