# Tigerest Theater 2.6.1 · Mac 高刷新率与 iPad 首版

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Windows 安装版 | [2.6.1 EXE][dl-win-exe] | Windows 10 1903+ / Windows 11，x64 |
| Windows 便携版 | [2.6.1 ZIP][dl-win-zip] | 同上；完整解压后运行 |
| Android | [2.6.1 APK][dl-android] | Android 15+，arm64-v8a / x86_64 |
| Apple Silicon Mac | [2.6.1 DMG][dl-mac] | macOS 26+，M 系列芯片 |
| iPad | [2.6.1 IPA][dl-ipad] | iPadOS 26+，须自行签名安装 |

本次提供 **Apple Silicon Mac（macOS 26+）** 和 **iPad（iPadOS 26+）**；**Windows** 与 **Android** 2.6.1 随后在同一发行页补充，见下方[Windows 与 Android](#windows-与-android)。

## Mac

- 修复网页界面的60 Hz回退，按屏幕刷新率运行；GPU-Next界面改用Metal，保留原生播放和桌面功能。
- 后台准备图片与模糊背景，减少切页时的重复解码、整页样式重算和快照控件初始化。
- 保留原来的毛玻璃、海报移动、首页入场及画质效果。正常重复转场实测约117–119 rAF/s，海报墙滚动118.33 rAF/s；首次详情仍可能出现短暂停顿。不是所有设备与场景恒定120帧的保证。

## iPad

- 专属／自建服务器选择、媒体库、详情、原生MPV、播放进度、离线媒体和客户端设置。
- 滑动快进快退、右侧音量、左侧亮度、长按倍速与锁定；修复锁定提示隐藏、OSD隐藏后空格暂停、上一集／下一集，选集显示SXXEXX，播放时隐藏时间／电量状态栏。
- 弹幕接口搜索和别名匹配与PC对齐；弱标题详情查询每接口最多五个，强匹配不受此限制。修复《青之箱》别名漏匹配和中文描边，弹幕由独立显示时钟驱动。
- 主设置提供画质预设和可选RIFE。补帧默认关闭，当前限定1920×1080、BT.709 SDR、23–30 fps，固定两倍；其他输入保留原帧。不宣称HDR、4K或所有iPad均能实时补帧。
- 支持检查正式版本、查看说明和跳过版本；免费签名安装通过Mac／自行重签名更新。

## Windows 与 Android

- Windows 网页界面不再固定 60 帧，按窗口所在屏幕的刷新率运行；打开平滑滚动，每格滚轮 150 px。
- Windows／Android 同步上述共用网页界面的转场优化；Windows 弹幕别名匹配与 iPad 一致。Android 原生部分与 2.6.0 相同。
- 安装包：`TigerestTheater-2.6.1-x64.exe`、`TigerestTheater-2.6.1-x64.zip`、`TigerestTheater-2.6.1-android.apk`。

详细变化、测量与验证范围见 [Windows 与 Android 2.6.1 说明](2026-10-14-v2.6.1-windows-android.md)。

## 安装

- `TigerestTheater-2.6.1-arm64.dmg`：退出旧客户端，把应用拖入“应用程序”替换，保留原用户数据。使用ad-hoc签名，尚未经过Apple公证。
- `TigerestTheater-2.6.1-ipad.ipa`：**未签名，须使用自己的Apple身份重签名后安装**，不含作者个人签名或设备资料。免费账号可通过Xcode构建安装，签名需按Apple规则续签。不是App Store／TestFlight包。见[iPad安装说明](https://github.com/Tigerest/Tigerest-Theater/blob/v2.6.1/docs/apple/INSTALL.md)。
- `TigerestTheater-2.6.1-SHA256SUMS.txt`：校验本次发行文件（Windows 与 Android 补充发布后一并列出）。

没有对应平台附件的版本会被更新器跳过，Windows不会下载Mac／iPad附件。Mac预览与正式安装使用的配置档可能不同，请从原有正式配置继续使用。

## 验证范围

Mac进行了同机关闭／开启／关闭对照、三轮真实媒体库导航、滚动及原生像素／生命周期／快照回归；详见[完整测量](../reports/2026-10-14-mac-120hz.md)。保留先前同一引擎的播放、shader及运行库验证，不把界面帧率当成实际视频或屏幕扫描帧率。

iPad使用Xcode27构建Release，AppleCore 44项通过；桥接5项及shader资源一致性通过。IPA检查设备架构、最低系统、28个Mach-O、Web资源与RIFE模型，并在隔离副本验证可重新签名。此次无签名包不能直接真机启动；既有同一播放实现的真机视频、手势、弹幕与RIFE验证见[iPad记录](../apple/2026-10-14-ipad-feedback-verification.md)。

Windows构建已同步2.6.1的RIFE兼容版本清单，扩展、ABI与校验值未变。Windows 与 Android 的测试和打包验证见[单独说明](2026-10-14-v2.6.1-windows-android.md)。原有Windows高刷新率窗口播放已知问题仍见[排查文档](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。
