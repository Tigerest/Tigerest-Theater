# Tigerest Theater 2.9.5.2 · mpv.conf 编辑器自动换行（Windows、Mac）

本次发布 Windows（安装版和便携版）与 Mac。Android、iPhone／iPad 与 Apple TV 仍是 2.9.5，安装包在 [2.9.5 发行页](https://github.com/Tigerest/Tigerest-Theater/releases/tag/v2.9.5)；这些平台的检查更新不会提示这一版。Windows 和 Mac 的 2.9.5、2.9.5.1 检查更新会提示 2.9.5.2。

## mpv.conf 编辑器自动换行（Windows、Mac）

- **问题：** 「设置 → MPV 画质与插件」下方的 mpv.conf 编辑器不换行。一行太长时，编辑区可以被左右拖动和滚动，行首的字符被挡在左边；中文比英文字母宽，长的中文注释最明显。
- **修复：** 超出宽度的行在编辑器里折行显示，编辑区不再左右滚动。行号、错误和警告标记、被 RIFE 暂停或忽略的行的底色，以及行间的「+」插入按钮，都跟着折行后的高度对齐。客户端维护的头部和尾部，以及「恢复默认配置」、默认配置有变化和粘贴时显示的改动对比，也改为折行。
- 折行只影响显示，保存的 mpv.conf 内容不变。其他功能与 2.9.5.1 相同。

## 安装

- `TigerestTheater-2.9.5.2-x64.exe`：Windows 安装版；或完整解压 `TigerestTheater-2.9.5.2-x64.zip` 便携版（保留 `data`）。在 2.9.5 或 2.9.5.1 的更新窗口点「安装更新」会自动关闭、静默安装并重新打开。2.9.4 的检查更新识别不了四段版本号，会先提示 2.9.5，装好后再检查一次就能升到 2.9.5.2，也可以直接运行这一版的安装包；从 2.9.3 及更早版本升级时完全退出客户端后运行安装向导。未做 Authenticode 签名。
- `TigerestTheater-2.9.5.2-arm64.dmg`：Apple Silicon Mac，macOS 26+。打开后把应用拖入「应用程序」替换旧版；Mac 2.9.5 和 2.9.5.1 的更新窗口会找到这个文件。使用 ad-hoc 签名，未经 Apple 公证。
- 两个平台的播放内核、补帧组件和修补版 QtWebEngine 都与 2.9.5.1 相同。Windows 播放内核的原始构建产物 `Tigerest-mpv-rife-x64-5122104.zip` 在 [2.9.5.1 发行页](https://github.com/Tigerest/Tigerest-Theater/releases/tag/v2.9.5.1)，修补版 QtWebEngine 的组件包见 [2.9.4 发行页](https://github.com/Tigerest/Tigerest-Theater/releases/tag/v2.9.4)的 `TigerestWebEngine-6.9.3-d3d11.zip`。
- `TigerestTheater-2.9.5.2-SHA256SUMS.txt` 校验本页全部文件；`RELEASE-MANIFEST.json` 记录来源提交、内核来源和验证范围。源码：`client-Sources.zip`（全部客户端，本版的发布提交；Windows 和 Mac 的构建提交都包含在内，之后的提交只改测试和文档）。
- 已安装的 Windows RIFE 扩展可以继续用于 2.9.5.2，不用重新下载。
- 无法访问 GitHub 时，可从[夸克网盘](https://pan.quark.cn/s/88e6f7a795b4)或[百度网盘](https://pan.baidu.com/s/58azzOU4piiB3miyZqA1dig)的 `2.9.5.2` 文件夹下载同样的 Windows 安装包，用 `SHA256SUMS.txt` 校验。

## 验证范围

- **Windows 发布构建：** 安装包和便携包从 `f82f064` 构建（打开检查更新）；之后的提交只改测试和文档，测试不进安装包。完整串行 CTest 122 个目标中 121 个通过（564 秒）。mpv.conf 编辑器的界面测试 `test_mpvconf_editor_webengine` 新加了换行检查：在长行里把光标移到行尾，编辑区不横向滚动；编辑区、文本框和客户端维护的头尾都没有横向溢出；逐行比对折行后的高度和行号格子，包括行尾有大量空格和以制表符开头的行；「+」按钮对准行间；检查结束后磁盘上的文件没有变化。没通过的 `test_home_gallery_webengine` 是测试自身的问题：首页媒体库列表在鼠标悬停时会预览那个媒体库，测试窗口弹出时桌面上的鼠标正好停在列表上，测试点开的作品就变了。单独连跑 11 次失败 3 次，与这一版的改动无关。
- **Windows 安装包：** 便携包 1534 个文件与暂存目录逐字节一致，OpenSSL、播放内核（两个 DLL 角色是同一份）与修补版 QtWebEngine 的哈希与锁定值一致；和 2.9.5.1 的便携包逐文件比较，只有主程序不同。程序内的构建号为 `f82f064a`，构建日期 2026-11-03。便携包解压到新文件夹、用独立配置打开后，人工试用过 mpv.conf 编辑器。
- **Mac：** DMG 在 Mac 上从 `f54910f` 构建（之后的提交只改文档），SHA-256 与 Mac 构建时记录的一致。在 Windows 上拆开 DMG，与 2.9.5.1 的 DMG 逐文件比较：都是 2782 个文件，236 个二进制里只有主程序不同，播放内核、补帧和修补版 QtWebEngine 逐字节相同；其余不同的是 Info.plist（版本 2.9.5.2）、构建记录、签名清单，以及打包时重新编译的 RIFE Core ML 模型描述（模型权重不变）。程序内的构建号为 `f54910ff`，构建日期 2026-11-03。这里只列出在 Windows 上对 DMG 做的核对。
- 网页测试均使用隔离配置和离线夹具；生产接口只收到只读的检查更新请求，没有用真实 Emby 账号登录。附件哈希以发行页的 `TigerestTheater-2.9.5.2-SHA256SUMS.txt` 和 `RELEASE-MANIFEST.json` 为准。

## 已知问题

- 不开补帧、使用默认的「显示器重采样」时，部分 Windows 高刷新率环境下窗口播放仍可能持续卡顿、增加输出丢帧，全屏正常。这个问题仍未修复；遇到时请先全屏播放，见[故障排查](https://github.com/Tigerest/Tigerest-Theater/wiki/Troubleshooting)。
- 窗口播放剩下的抖动主要来自系统合成，和桌面活动有关（例如任务栏时钟显示秒数时，桌面每秒重绘一次）；全屏最平滑。
- Mac：本次运行中开始播放过以后，在设置里保存 mpv.conf 会丢掉 SVP 的连接设置，SVP 要到下次打开客户端才能重新连上。2.9.4 起就有这个问题，2.9.5.2 仍未修复。
- 全屏开着弹幕、按音频时钟播放时，10 分钟测试里出现过一次约 0.15 秒不出新画面（随后掉 2 帧），卡在处理弹幕图层的阶段，原因还没查清。
- 2.9.5.1 的高刷新率节奏改进只在一台 4K 240 Hz 显示器和 RTX 4090 上实测，其他刷新率、显示器和显卡还没验证；也还没在 Emby 串流和网页界面下测过节奏。
- 本地播放还不能把文件直接拖进已经打开的窗口（拖到程序图标或快捷方式上可以），也不记录本地文件的续播位置。
- 返回一面这次还没显示过、图片也不在缓存里的海报墙时，服务器要 0.5–0.8 秒才给出目标卡片，转场约在 0.8–0.9 秒结束。
