# v2.5.1 更新下载与弹幕识别修复

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Windows 安装版 | [2.5.1 EXE][dl-win-exe] | Windows 10 1903+ / Windows 11，x64 |
| Windows 便携版 | [2.5.1 ZIP][dl-win-zip] | 同上；完整解压后运行 |
| Android | [2.5.1 APK][dl-android] | Android 15+，arm64-v8a / x86_64 |
| Apple Silicon Mac | [2.5.1 DMG][dl-mac] | macOS 26+，M 系列芯片 |

**本次 Windows 请手动更新。** 2.4.4～2.5.0 的内置更新器可能下载中断，请手动下载安装包，退出客户端后安装。便携版请退出后解压到新目录，并迁移自己的配置。安装本修复版后，后续更新可使用内置下载。

- Windows 随包部署并校验 OpenSSL 与对应 Qt TLS 插件，应用更新和 RIFE 扩展包下载共用该后端。
- 桌面和 Android 应用更新支持暂停、继续、退出重开后续传。取得新进度时继续重连；连续五次重试没有新进度才提示失败。
- 桌面取消下载固定 30 分钟时限，慢速但持续有数据的下载可以继续。
- 下载界面显示已下载大小、速度和重试状态。
- 文件变化或服务端不支持续传时安全重下，完整下载及安装前再次校验 SHA-256。
- RIFE 扩展已有断点续传，此次同步修复基础下载运行库，无需仅因网络修复重新下载已安装模型。
- 弹幕匹配去掉日期确认，按作品、季度和集数识别；对应作品与季度内，集标题唯一匹配时优先使用标题，不匹配时使用集数。仍有多个同等候选时可手动选择。

本次发布包含 Windows、Android 和补充的 Apple Silicon Mac 安装包。Mac 合并桌面更新器及无日期弹幕策略，并补齐“第二期／第2期”的季度名称识别；《转生成为魔剑了》S02E02 在首播日期错误指向第三集时，仍正确加载第二集弹幕。
